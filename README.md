## 🚀 Proyectos Destacados
#### 🚗 Urban Traffic Analysis
* **Descripción:** Proyecto de análisis exploratorio de datos (EDA) enfocado en explorar patrones de tráfico urbano e indicadores económicos en diferentes ciudades. El objetivo principal fue limpiar conjuntos de datos inconsistentes, estandarizar valores y generar hallazgos para respaldar la toma de decisiones basada en datos.
* **Tecnologías:** Python, Pandas, Matplotlib, Seaborn, Jupyter Notebook.
* **Principales Hallazgos:** 
  * Los patrones de congestión vehicular varían significativamente entre ciudades.
  * La fase de preprocesamiento y limpieza fue crucial debido a inconsistencias de formato en los datos originales.
  * Los indicadores económicos (como el PIB per cápita) muestran relación con el comportamiento del tráfico urbano.
* **Enlace:** [Ver repositorio de Urban Traffic Analysis](https://github.com/EdgarAlvz/urban-traffic-analysis)
